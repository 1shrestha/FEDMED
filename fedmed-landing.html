Why hospitals can't just pool their data

A tumor-segmentation model gets better with more MRI scans — but medical imaging data is some of the most tightly regulated data there is. Hospitals can't legally or practically ship patient scans to a shared server, and any single hospital's dataset is usually too small and too narrow to train a model that generalizes well.

Federated learning sidesteps the problem: instead of moving data to the model, FedMed moves the model to the data — training locally at each hospital and combining only the resulting knowledge, under encryption.

How a training round works

Five steps, repeated every round, across all three simulated hospital nodes. Scroll to see each one activate.

01

Local training

Each node trains a 3D U‑Net (PyTorch + MONAI) on its own MRI volumes. The scans never leave the hospital's own server.

02

Encrypted updates

Only the resulting model weight updates leave the node — homomorphically encrypted with TenSEAL, so no one downstream can read them in the clear.

03

Secure transport

Updates travel over gRPC with TLS between each node and the aggregation server, end to end.

04

Private aggregation

FedAvg combines the encrypted updates into one global model. Differential‑privacy noise is added so no single hospital's scans can be reverse‑engineered from the result.

05

Shared model, sent back

The improved global model — better than any one hospital could train alone — returns to every node for the next round.

Under the hood

The stack behind each part of the pipeline above.

Segmentation model

3D U‑Net PyTorch + MONAI

Trained on the BraTS brain-tumor MRI dataset; establishes the centralized-baseline accuracy the federated model is measured against.

Federated orchestration

FedAvg Flower / PySyft

Coordinates training rounds across all three simulated hospital nodes and handles a node dropping out mid-round.

Privacy layer

Encryption TenSEAL

Homomorphic encryption on every update before it leaves a node, plus differential-privacy noise at aggregation time.

Transport

Node ↔ server gRPC + TLS

Every message between a hospital node and the aggregation server is encrypted in transit.

Monitoring

Live dashboard React + Recharts

Streams per-node training metrics over WebSocket as each round runs.
