# FedMed

## Federated Medical Learning Framework

FedMed is a modular, extensible federated-learning framework designed for medical machine-learning research.

The project is being developed as a framework-independent federated-learning core first, followed by runtime integration, reproducible federated experiments, medical-specific research, privacy/security mechanisms, and production deployment.

The architecture is intentionally designed around clear separation of responsibilities so that individual components can evolve without requiring large-scale rewrites.
